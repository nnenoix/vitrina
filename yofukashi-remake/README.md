# Ремейк ролика: Назуна и Коу («Песнь ночных сов»)

`nazuna_kou_remake.mp4` — 720×1280, 30 fps, 533 кадра (17,77 с), то же, что у референса.
Все кадры нарисованы кодом с нуля. Из исходного ролика взята только аудиодорожка
(она копируется без перекодирования).

| Время | Сцена |
|---|---|
| 0–0,85 с | затемнение → пиксельный коридор, вид сверху |
| 0–2,72 с | Коу идёт вниз, Назуна стоит боком |
| 2,80 с | Назуна оборачивается, пузырь «HEY KOU-KUN!» |
| 3,67–4,23 с | экран схлопывается в линию, как у ЭЛТ |
| 4,37–5,50 с | экран разворачивается: ночной зал с готическими окнами |
| 4,93–5,90 с | выезжает диалоговое окно, с 4,97 с слева въезжает крупный план Назуны |
| 5,97 / 10,13 / 13,03 с | реплики печатаются по буквам, с паузами на «...» и запятых |
| 13,0 с → | на последней реплике у Назуны появляется румянец |
| 15,50–16,45 с | затемнение, дальше чёрный экран до конца |

Пересобрать видео (нужны `ffmpeg`, `numpy`, `pillow`, `pycairo`):

```
python3 render.py REFERENCE.mp4 nazuna_kou_remake.mp4
python3 render.py --frames OUT_DIR 1.0 8.8 14.9   # отдельные кадры для проверки
```

- `pixel_scene.py`: пол коридора и спрайты Коу и Назуны, расставленные по пикселям.
- `vn_bg.py`: зал с окнами, звёзды, луна и огни города.
- `vn_chars.py`, `draw.py`: векторная прорисовка персонажей.
- `font.py`: самодельный пиксельный шрифт.
- `render.py`: таймлайн, переходы, интерфейс диалога и сборка видео.
